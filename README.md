# 纳指溢价工作台

把「截图 → 手抄数字 → 算溢价」这套每天半小时的活，变成一个手机网页：
**打开地址就能看到 16 只纳指场内基金的实时溢价率、相对强弱排名和溢价分位**，不用电脑、不用 WPS、不用截图。

## 一、它替你做了什么

| 你以前做的 | 现在 |
|---|---|
| 同花顺截图 13 只价格 | 腾讯行情接口批量取，1 秒 |
| 天天基金截图净值（T-1） | 天天基金净值接口，自动算到最新 |
| 拿「前晚纳指涨幅 + 今日期货」手算真实净值 | 自动用「最新净值 × (1 + 仓位 × 指数自净值日以来涨跌)」估算 |

| 用 WPS 记溢价历史、看均值 | 自动维护 120 天溢价序列、20 日均值、60 日分位 |

## 二、十分钟部署（只需做一次）

### 1. 建仓库
- 打开 https://github.com/new
- 名字随便，比如 `ndx-premium`，选 **Public**（私有仓库的 Pages 要付费）
- 建好后把本文件夹里**除 `.cache` 以外**的所有文件传上去
  （网页上传：仓库页 → `Add file` → `Upload files` → 把 `config.json`、`run.py`、`fetchers.py`、`model.py`、`run.bat`、`README.md`、`docs/`、`.github/`、`tools/` 一起拖进去）

### 2. 开 Pages
- 仓库 → `Settings` → 左侧 `Pages`
- `Source` 选 **GitHub Actions**（不是 Deploy from a branch）
- 回到仓库 `Actions` 标签，点 `更新纳指溢价` → `Enable workflow` / `Run workflow` 跑一次

### 3. 手机上收藏
- 跑完在 `Actions` 里能看到部署地址，形如
  `https://你的用户名.github.io/ndx-premium/`
- 手机浏览器打开 → 添加到主屏幕，以后点一下就开

> 私有仓库、或者不想公开，也可以用手机上的 GitHub App 手动跑 workflow，但页面地址还是公开的（Pages 免费版必须公开）。

## 三、每天什么时候自动更新

| 北京时间 | 用途 |
|---|---|
| 09:20 | 开盘前，昨晚美股 + 期货已定，看今天该买谁 |
| 10:30 / 11:25 | 盘中看相对强弱变化 |
| 13:30 / 14:40 | 下午盘，调仓窗口 |
| 14:55 | 尾盘定盘价 |

GitHub 的定时任务用 UTC，已经换算好了，见 `.github/workflows/update.yml`。
定时任务**可能延迟几分钟**，页面上会显示「N 分钟前更新」和「盘中实时 / 收盘数据」状态。

> ⚠️ GitHub 规定：仓库连续 60 天没有提交，定时任务会自动暂停。偶尔点一次 `Run workflow`，或者随便改个文件提交一下，就会恢复。
> 如果你经常长时间不看，建议在手机日历里设个 50 天的提醒。

## 四、页面上每个数字是什么意思

- **溢价率**（大字）：`现价 / 估算净值 - 1`
- **估算净值**：`最新公布净值 × (1 + 仓位 × (当前指数等效点位 / 净值基准日的纳指收盘 - 1))`
  - 这一步就是你手算的「前晚涨幅 + 今日期货」的合并版，好处是**不会重复计算**：
    净值落后几天就补几天，净值已经反映的部分不会再叠加一次。
  - 指数等效点位：美股盘中直接用现价；美股休市时用「最后收盘 × (1 + 纳指期货涨跌)」。
  - 未做汇率调整（按你的口径忽略汇率；513300 的离岸人民币偏差只能算近似）。
- **距均值**：当前溢价 − 自己 20 日均溢价。正=比平时贵，负=比平时便宜。
- **60 日分位**：当前溢价在过去 60 个交易日中的位置，97% 就是「比 97% 的日子都贵」。
- **年内涨幅**：用前复权收盘价算，剔除分红影响。
- **相对强弱**（近 20 日超额）：这只基金的 20 日涨幅 − 12 只纳指 100 ETF 的平均 20 日涨幅。
  越负 = 越弱 = 按你的策略越该盯着买。
- **信号**：
  - `买入候选`：距均值 ≤ −1%，且近 20 日跑输同行
  - `偏贵/可换出`：距均值 ≥ +1.5%，且近 20 日跑赢同行
  - 其余为 `观察`
- **对冲窗口横幅**：平均溢价 ≥ 9%，且高于 20 日均值 2% 以上时出现，对应你笔记里「场外 QQQ 对冲」的触发线。

点任意一行，可以看这只基金 90 天溢价走势、当日 15 分钟走势和全部明细。
支持直达链接：`.../#` 或 `?c=513100` 直接打开某只基金。

## 五、你要维护的东西

### 限购额度（每天看一眼，填一次）
`config.json` 里每只基金有 `"limit": null`，填成 `"limit": "暂停申购"` 或 `"limit": "1万"` 即可，页面和详情页会显示。
手机上改：GitHub 网页版 → `config.json` → 右上角铅笔 → 改 → Commit。

### 增删基金 / 改仓位
同样在 `config.json`：
- `peers` 里加一行：`{"code": "513500", "market": "sh", "name": "标普500ETF", "pos": 0.95, "type": "ETF", "enabled": true, "limit": null, "note": ""}`
- `market` 填 `sh`（5 开头）或 `sz`（1 开头）
- `pos` 是股票仓位，影响净值估算，默认 0.95；标普信息科技（161128）按你的笔记填了 0.90
- `settings.core_codes` 是算「平均溢价」用的 12 只，改这里就改基准

改完点一次 `Run workflow` 生效，不用等定时。

## 六、本地跑（可选）

Windows 双击 `run.bat` 即可，跑完自动打开 `docs/index.html`。
需要 Python 3.9+（https://www.python.org/downloads/ ，安装时勾选 Add to PATH）。
不联网也能看上次结果，但数字是旧的。

### 导回 WPS 继续做你的分析
```
python tools/to_excel.py
```
生成 `纳指溢价_日期.xlsx`：第一张表是当日快照，第二张表是 120 天溢价率矩阵，
可以直接粘进你原来的 `纳指溢价差.xlsx`。

## 七、手机推送（可选，但出差时很香）

每天 14:40 那次跑完，把前 3 名推到手机：
- **Bark**（iOS）：App 里拿到推送地址，形如 `https://api.day.app/你的key`，
  仓库 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`，
  名字 `BARK_URL`，值粘进去。
- **Server酱**（微信）：拿 SendKey，同理建 secret `SERVERCHAN_KEY`。

没配就跳过，不影响网页。

## 八、出问题了怎么办

| 现象 | 原因 / 处理 |
|---|---|
| 页面写着「N 分钟前更新」变黄 | 那次定时任务没跑或失败了，去 `Actions` 看日志，点 `Run workflow` 手动补一次 |
| 有的基金显示「数据缺失」 | 该基金当天停牌/净值未更新，或者接口临时失败；重跑一次通常就好 |
| 所有基金都缺失 | 大概率是数据源限制了你所在的网络。GitHub 的服务器在国外，国内接口偶尔会拦。见下条 |
| Actions 天天失败 | 换国内机器跑（见下），或者改用你家里的常开设备 |

### 备选：放到国内服务器跑（最稳）
任意一台国内云主机（2 核 1G 足够，几十块一年）：
```bash
# 装 Python 后
crontab -e
# 每 30 分钟一次，交易时段
*/30 9-15 * * 1-5 cd /opt/ndx-premium && python3 run.py >> log.txt 2>&1
```
再把 `docs/` 用 nginx 挂出来，或同步到任意静态托管。
国内 IP 访问东财/腾讯/天天基金最稳，也彻底避开 GitHub 的 60 天休眠。

### 不想要网页，只想每天收到一条消息
配好上面的 Bark / Server酱，然后关掉 Pages，只看推送。

## 九、目录说明

```
ndx-premium/
├─ config.json          基金清单、仓位、限购、基准（你要改的就是这个）
├─ run.py               主程序：抓数据 → 算 → 生成网页数据
├─ fetchers.py          数据抓取层（腾讯/新浪/天天基金/东财，多源互备 + 缓存）
├─ model.py             计算层：估算净值、溢价、分位、相对强弱、信号
├─ docs/
│  ├─ index.html        手机页面（单文件，无需构建）
│  ├─ data.js           每次运行生成的数据
│  └─ data.json         同上，给程序读的
├─ tools/to_excel.py    导出 WPS/Excel
├─ .github/workflows/update.yml   定时任务 + Pages 部署
└─ run.bat              Windows 本地一键运行
```

## 十、说明

- 数据全部来自公开行情接口，仅供个人研究，不构成投资建议。
- 估算是近似值：汇率、基金仓位变动、跟踪误差、成分股调整都会带来 0.1%~0.5% 的偏差。
  真正下单前，高溢价品种仍建议对照集思录/同花顺的实时 IOPV 复核一眼。
- 溢价率的历史序列用「收盘价 ÷ 当日净值」计算，与你表里 `主要跟踪品种` 的口径一致。
